# Web前端主知识库格式规范

> 适用对象：负责补题、改题、扩充 Web 前端主知识库的项目成员
> 当前阶段：最小可用版本
> 目标：保证前端主知识库可以复用现有入库脚本和后续面试流程

---

## 1. 主库定位

Web 前端主知识库用于：

- 模拟面试出题
- 标准回答检索
- 追问生成
- 回答评估
- 面试反馈生成

它应采用与 Java 主库一致的“单题结构化”格式，便于统一接入平台。

---

## 2. 单题固定结构

每道题必须包含以下小节：

- 元数据
- 面试题
- 标准回答
- 追问点
- 评分点
- 常见失分点

题目标题统一采用：

- `## Q001 ...`
- `## Q002 ...`

---

## 3. 元数据推荐字段

```md
### 元数据
- 岗位：Web前端开发工程师
- 题型：技术知识
- 主题：前端基础
- 难度：初级
- 关键词：`JavaScript` `作用域` `闭包`
```

当前推荐主题包括：

- 前端基础
- 浏览器
- React
- Vue
- 前端工程化
- 前端性能优化
- 项目
- 行为题

---

## 4. 兼容性要求

为了兼容当前 `scripts/ingest_data.py`：

- 小节标题必须统一使用 `###`
- 题目标题必须统一使用 `## Qxxx`
- 文件编码统一为 `UTF-8`
- 不要改动“面试题”“标准回答”等小节名称

---

## 5. 当前策略

本岗位当前只需要维持最小可用内容，满足后续整平台接入。

完整扩充工作可由后续组员继续补齐。
