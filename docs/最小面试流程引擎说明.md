# 最小面试流程引擎说明

## 1. 目标

本模块用于把当前已有的多岗位知识库和 RAG 能力，串成一个最小可用的文本模拟面试流程。

当前版本优先解决：

- 选择岗位
- 生成首题
- 提交回答
- 生成追问
- 给出基础评估
- 结束面试并输出总结

它不是最终版后端服务，但已经可以作为后续平台联调的流程底座。

---

## 3. 支持的岗位

当前已接入：

- `web_frontend`

## 4. 核心设计

### 4.1 双路取题

脚本会优先尝试：

1. 从 Chroma collection 检索首题
2. 如果检索失败，则回退到本地主知识库 Markdown 解析

这样做的好处是：

- 正常环境下可以直接演示 RAG
- 即使本地向量库环境不稳定，也不影响流程层开发

### 4.2 会话状态

每次开始面试后，会在本地生成一个 session 文件，默认目录为：

- `D:\AI_Interview_Project\runtime\sessions\`

session 中会保存：

- 会话 id
- 岗位
- 当前题目
- 回答历史
- 每轮评估结果
- 当前追问

### 4.3 当前评估方式

当前版本使用轻量规则评估，不依赖在线大模型：

- 关键词覆盖
- 评分点命中
- 回答长度
- 逻辑连接词
- 岗位匹配度

后续可平滑替换为大模型评分。

## 5. 支持的命令

### 开始一场面试

```powershell
D:\AI_Interview_Project\scripts\.venv\Scripts\python.exe D:\AI_Interview_Project\scripts\interview_flow.py start `
  --role java_backend `
  --topic collection `
  --difficulty medium `
  --question-query "HashMap"
```

### 提交一轮回答

```powershell
D:\AI_Interview_Project\scripts\.venv\Scripts\python.exe D:\AI_Interview_Project\scripts\interview_flow.py answer `
  --session-id <session_id> `
  --answer "HashMap 底层是数组、链表和红黑树..."
```

### 结束并查看总结

```powershell
D:\AI_Interview_Project\scripts\.venv\Scripts\python.exe D:\AI_Interview_Project\scripts\interview_flow.py finish `
  --session-id <session_id>
```

### 生成结构化报告

```powershell
D:\AI_Interview_Project\scripts\.venv\Scripts\python.exe D:\AI_Interview_Project\scripts\interview_flow.py report `
  --session-id <session_id>
```

### 查看当前 session 原始状态

```powershell
D:\AI_Interview_Project\scripts\.venv\Scripts\python.exe D:\AI_Interview_Project\scripts\interview_flow.py inspect `
  --session-id <session_id>
```
